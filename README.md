# README

## 消去しりとり（DeleteTailtoNose）

五十音を持ち駒として使うしりとりゲームです。

- CPU対戦
- ローカル対戦
- オンライン対戦（PeerJSのP2Pルーム、最大4人）
- 先頭の文字は前の単語の末尾を引き継ぐ
- 「ん」で終わる単語を言うと負け
- ギブアップすると相手の勝ち
- 1回使った駒は二度使えない
- 持ち駒がなくなれば勝利
- 持ち駒で作れる単語がなくなれば敗北
- JMdictとSudachiDictを元にした辞書をローカル検索する（プレイ中の通信は不要）

## 実行方法

```bash
npm install
npm run dev -- --host 0.0.0.0
```

ブラウザで表示されたURLを開いて遊んでください。

## GitHub Pagesで公開

`main` ブランチにpushすると、GitHub ActionsがビルドしてPagesへ公開します。GitHubリポジトリの Settings > Pages で、公開元を「GitHub Actions」に設定してください。

公開URL: https://loser-yuma.github.io/DeleteTailtoNose/

## ルールメモ

- 最初の単語は自由に決められます。
- 2回目以降は、前の単語の最後の文字で始める必要があります。
- 単語中の先頭文字は引き継ぎの文字として消費されません。
- そのほかの文字は、自分の持ち駒から使う必要があります。
- 清音と濁音は同じ拍として扱い、濁音は清音に変換して判定します。
- 辞書データのライセンスと出典は`public/DICTIONARY_LICENSES.txt`に記載しています。

## オンライン対戦

対戦モードで「オンライン対戦」を選び、ホストがルームを作成します。表示された6桁の招待コードを共有し、参加者がコードを入力して参加してください。ホストを含めて最大4人で遊べます。

接続にはPeerJSのシグナリングサービスを使用し、ゲーム中の状態はホストのブラウザが管理します。GitHub Pagesなどの静的ホスティングでも動作しますが、参加者全員にインターネット接続が必要です。
